# Inspirações

> Produtos que inspiraram o desenho do SelfEvoPI.

## Claude Code (Anthropic)

- **URL:** https://code.claude.com/docs
- **O que copiamos:**
  - Paleta de comandos com filtro por prefixo
  - Ciclo de permission modes com `Shift+Tab`
  - Shell mode com `!`
  - Indicador de modo na status bar
  - `/cost` e `/context` (transparência)
  - `/rewind` (checkpoint)
  - Skills customizadas via `SKILL.md`
  - `Ctrl+R` busca reversa
  - Background tasks com `Ctrl+B`
  - Linha de controle + configurador

## OpenCode

- **URL:** https://opencode.ai
- **O que copiamos:**
  - Skills em `~/.config/opencode/skills/`
  - MCP em `~/.config/opencode/opencode.jsonc`
  - Interface limpa, foco no prompt

## Cursor

- **URL:** https://cursor.com
- **O que copiamos:**
  - Codebase indexing (referência)
  - Tab completion (referência)

## Zed

- **URL:** https://zed.dev
- **O que copiamos:**
  - Performance (Rust, GPU) como meta
  - Interface minimalista

## Warp

- **URL:** https://warp.dev
- **O que copiamos:**
  - Blocks (referência para organização de output)
  - AI terminal (referência)
