## 5. Nota sobre a instabilidade da medição

Três fatos, todos medidos:

1. **A máquina estava carregada.** 48 processos `node` vivos durante a medição de cold start (outros agentes/trabalho concorrente).
2. **O controle isola a causa.** `node -e 0` (só o Node, sem o SelfEvoPI), 7 execuções:

  | # | ms |
  |:--|:--|
  | 1 | 82.4 |
  | 2 | 87.5 |

  | 5 | 90.4 |

  Se o próprio Node oscila de 81,2 a 210,5 ms nesta amostra (e foi a 74,8 em outra rodada do dia), parte da variação do SelfEvoPI é do sistema operacional, não do código.

### Como publicar

- Cold start: **mediana + data**, com a nota de que há cauda sob carga. Nunca só a média.
- Motor: idem.
- Overhead: manter o número, mas **marcar a data da medição original** (2026-11-17/18) — a reconfirmação de 2026-11-19 foi bloqueada por quota, não por mudança de código.
- Testes: separar os dois escopos na tabela. O número do `npm test` não é o número do comando estreito.

## 7. Reprodutor

Os scripts de medição usados ficam fora do repositório (são temporários). O método, para reproduzir:

```powershell
# cold start — 7 execuções, aquecimento descartado
$tempos = @()
1..7 | ForEach-Object {
  $t = [Diagnostics.Stopwatch]::StartNew()
  node apps/cli.mjs --version | Out-Null
  $tempos += $t.Elapsed.TotalMilliseconds
}
"$($tempos -join ', ') ms"
($tempos | Measure-Object -Average).Average
($tempos | Sort-Object)[3]

# motor
node "$env:APPDATA\npm\node_modules\@earendil-works\pi-coding-agent\dist\bundle\cli.js" --version

# overhead (bloqueado por quota nesta data)
node scripts/measure-selfevopi-overhead.mjs --runs 3

# testes
node --test core/agent/*.test.mjs apps/*.test.mjs apps/desktop/*.test.mjs
npm test
```
