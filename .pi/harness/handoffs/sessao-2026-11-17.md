```

```

API HTTP:

| Método | Rota |
|:---|:---|
| GET | `/health` |
| POST | `/sessions` |
| GET | `/sessions` |
| GET | `/sessions/:id` |
| DELETE | `/sessions/:id` |
| POST | `/sessions/:id/messages` (SSE) |
| POST | `/sessions/:id/steer` · `/followup` · `/cancel` |

Tipos: `SessionResponse { sessionId, status, createdAt }`,
`HealthResponse { status, sessions, uptime, version }`,
`CreateSessionRequest { sessionId?, provider?, model?, systemPrompt?, toolsEnabled?, workspaceDir? }`.

Sessão do pi em disco: `~/.pi/agent/sessions/<cwd-codificado>/<iso>_<uuid>.jsonl`.

nesta sessão: com o loop auto-disparado (A5), o código gerado passa a executar muito
mais vezes, e o sandbox vira a única coisa entre o artefato e a máquina.
